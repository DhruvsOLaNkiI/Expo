⏱️  3-STEP QUICK START (10 MINUTES):

  Step 1: Get MongoDB Connection String
  ───────────────────────────────────────
  • Go to: https://cloud.mongodb.com
  • Create free cluster
  • Click: Connect → Drivers → Node.js
  • Copy: Your connection string

  Step 2: Update .env File
  ────────────────────────
  Open: .env (in project root)
  Find: MONGODB_URI=your_mongodb_connection_string_here
  Replace with your actual connection string

  Step 3: Restart Dev Server
  ──────────────────────────
  Run these commands:
    npm install
    npm run dev

  Wait for console message:
    ✓ Connected to MongoDB successfully

❓ COMMON QUESTIONS:

  Q: Where do I put the connection string?
  A: In .env file, in the MONGODB_URI= line

  Q: Will it work on Vercel?
  A: Yes! Add MONGODB_URI as Environment Variable in Vercel settings

  Q: Do I need to change anything in my React code?
  A: Optional. API works automatically. Can enhance AiChatbox.tsx later

  Q: What happens if MongoDB is down?
  A: Trees won't save/load. But PageIndex still works (uses browser state)

  Q: Can I use the same MongoDB for multiple apps?
  A: Yes! Each app can have its own database (virtual-expo, etc)
